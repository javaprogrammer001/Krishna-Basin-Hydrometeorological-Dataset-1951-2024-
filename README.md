# Krishna Basin Hydrometeorological Dataset (1951–2024)

This repository contains hydrometeorological datasets collected and preprocessed for river flow forecasting, hydrological modeling, and machine learning applications in the Krishna River Basin.

## Study Location

Station: Wadenapally

Basin: Krishna River Basin, India

## Dataset Overview

The repository currently contains daily observations from multiple sources:

### 1. Rainfall Data

Daily rainfall observations for Wadenapally station.

Period:
- 1950–2000
- 2001–2024

Processing performed:
- Date standardization
- Detection of missing dates
- Reconstruction of complete daily calendar
- Missing observations preserved as NA

Variables:

| Variable | Unit |
|-----------|------|
| Rainfall | mm/day |

---

### 2. Maximum Temperature Data

Daily maximum temperature observations.

Period:
- 1951–2024

Variables:

| Variable | Unit |
|-----------|------|
| Tmax | °C |

---

### 3. Minimum Temperature Data

Daily minimum temperature observations.

Period:
- 1951–2024

Variables:

| Variable | Unit |
|-----------|------|
| Tmin | °C |

---

### 4. Streamflow / Discharge Data

Daily discharge observations from Wadenapally gauging station.

Variables:

| Variable | Unit |
|-----------|------|
| Discharge (Q) | m³/s |
